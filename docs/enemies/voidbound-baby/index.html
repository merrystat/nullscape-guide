Voidbound Baby 이미지 자리

외형

Baby의 어두운 변종으로 보라색 빛과 뾰족한 뿔, 날카로운 이를 가집니다.

특징

Baby와 비슷한 행동을 하지만 더 빠르고 더 긴 대시를 합니다. 돌진 음성이 더 작고 대시 표시가 빠르게 사라집니다.

회피법

대시 표시를 보고 빠르게 옆으로 피하세요. 대시 이후 위치 예측이 어려우므로 가능한 한 멀리 떨어져야 합니다.

팁

오디오 큐가 Baby보다 약간 더 약하니, 시각 표시와 움직임을 더 신경 쓰세요.

Notes

  • • Baby의 Voidbound 변종으로 대시 빈도와 거리가 증가합니다.
  • • 표시가 빨리 사라져서 추적이 더 어렵습니다.
  • • 대시 소리가 더 작아서 청각으로 파악하기 어렵습니다.
  • • 2마리 이상의 Baby를 선택하면 등장 확률이 생깁니다.
