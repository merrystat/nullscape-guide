외형

선명한 3개의 눈을 가진 불꽃 형태의 적으로, 뒤에 기둥(Pillar)과 화환(Wreath)이 있습니다. 카운트가 시작되면 화면 왼쪽에 나타나며, 카운트마다 기둥이 조금씩 시계 방향으로 회전합니다.

특징

무작위로 활성화되어 화면에 목표 숫자를 잠시 표시한 뒤 1부터 카운트를 시작합니다. 카운트가 처음 보여준 목표 숫자에 도달했을 때 어빌리티를 사용하고 있으면 Kolóna가 사라집니다. 실패 시 화환이 빨간색으로 변하고 기둥이 빠르게 회전하다가 잠시 후 플레이어를 처치합니다. 목표 숫자 이전에 미리 어빌리티를 사용해도, 목표 숫자 표시 시점에 어빌리티가 활성 상태면 성공으로 인정됩니다. Prisoner 클래스는 어빌리티가 없어 Kolóna가 등장하지 않습니다. Flesh에 감염되면 Kolóna가 살점으로 덮이며 타이머가 일시 정지됩니다.

회피법

처음 표시된 목표 숫자를 기억한 뒤, 카운트가 그 숫자에 도달하는 순간 어빌리티를 사용하세요. 숫자를 놓쳤다면 5 이후 매 카운트마다 어빌리티를 준비하세요. 최솟값이 5이므로 이 방법으로 생존을 보장할 수 있습니다.

팁

기둥은 매 카운트마다 22.5°씩 회전하므로 기둥 각도로 현재 카운트를 역산할 수 있습니다. 설정에서 '중앙 적 표시(Centered Enemies)' 옵션을 켜면 목표 숫자가 화면 중앙에 크게 표시되어 인식이 훨씬 쉬워집니다(카운트 중에는 Kolóna 위치로 돌아옴). Medal 획득 시 해당 라운드에서 Kolóna가 더 이상 등장하지 않습니다.

클래스별 대응법

Charger—퀵 드롭으로 어빌리티 체크 통과 가능
Diver—짧게 잠수 후 즉시 취소로 이동 흐름 유지
Grappler—지면에 짧게 그래플해 체크 통과
Glider—지면에서 어빌리티 단기 사용, 빠른 스팸 가능
Wanted—어빌리티 사용 쉬우나 운동량이 완전히 멈춤
Spirit—유령 폼 종료 타이밍에 패링 가능(권장하지 않음)

Notes

  • • Kolóna는 기존 적 Kookoo의 대체 적으로, Patch 5에서 도입되었습니다.
  • • Kookoo의 숫자 범위가 8~12였던 것에 비해 Kolóna는 5~15로 범위가 넓습니다.
  • • Kolóna는 그리스어·슬로바키아어로 '기둥'을 의미하며, 설계에 기둥이 포함된 이유입니다.
  • • Medal 획득 시 해당 라운드에서 Kolóna가 등장하지 않습니다. 이미 활성화된 상태에서 Medal을 얻으면 카운트 속도가 크게 빨라지지만 목표 숫자에 도달해도 처치하지 않습니다.
  • • Lost Embers 저주 적용 시 카운트 중 현재 숫자가 표시되지 않습니다. 기둥 각도로 카운트를 파악해야 합니다.
  • • Flesh에 감염되어 타이머를 의도적으로 멈추는 것은 가능하나, 숫자를 기억하는 것이 더 권장됩니다.
  • • Kolóna는 Global Kills 영역에 전적판이 없습니다.

관련 저주 상세

불타는 꽃다발 (Burning Bouquet)

"Kolóna가 Razorbloom을 불러들입니다." — Kolóna가 등장하면 Razorbloom도 즉시 함께 등장합니다.

잃어버린 불씨 (Lost Embers)

"Kolóna가 카운트 중 숫자를 더 이상 표시하지 않습니다. 주의하세요." — 기둥 각도와 회전 속도로 카운트를 파악해야 합니다.
